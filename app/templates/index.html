第 1 步：选择视频文件

浏览并选中要写入 NFO 的目标视频文件，NFO 和图片将生成到该文件所在目录。

第 2 步：刮削搜索

输入影片番号（如 IPVR-335）或 javdb 页面 URL 进行搜索刮削。选择视频文件后，文件名会自动填入搜索框。

输入番号将搜索相关影片，输入 URL 将直接刮削。

设置

从浏览器 F12 → Application → Cookies 复制完整 Cookie 字符串。

启用后 poster、fanart、extrafanart 逐个下载写入，避免 FUSE 网络文件系统并发 I/O 断开。

防止同目录并发刮削（多用户 Web 场景需要，单人使用建议关闭）。

每次文件写入前的停顿秒数，网络文件系统不稳定时调大（如 0.5）。设为 0 关闭。

extrafanart 最大保存数量，设为 0 完全禁用。
